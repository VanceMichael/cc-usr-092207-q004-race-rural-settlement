# 山野赛事惠农结算

核对山野赛事中的消费券、农产品销售与旅游服务结算。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括赛事运营方、本地农产品商户、文旅服务商、游客与参赛者、财政部门与主办单位。

资料除参与方、事实与约束外，还包含：

- `processes`：消费券与文旅服务的状态机（预占 → 核销 → 退款红冲 / 履约）
- `scenarios`：退赛、暴雨缩短活动、商户换摊三类异常的自付与补贴退款去向
- `invariants`：一次性核销码、幂等键、券状态机并发控制、订单按行拆分、部分退款同比例等防重复补贴规则
- `reports`：逐笔优惠承担台账、新增销售、赛后复购、已收款未履约服务

完整设计见 [`docs/design.md`](docs/design.md)。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
