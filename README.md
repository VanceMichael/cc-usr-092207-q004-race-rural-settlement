# 山野赛事惠农结算

核对山野赛事中的消费券、农产品销售与旅游服务结算。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括赛事运营方、本地农产品商户、游客与参赛者、补贴资金管理人员。

资料所依据的领域事实如下：

- 赛事现场设置特色农产品展销区
- 活动通过消费券和旅游路线推介连接在地产业
- 主办方希望形成体育、农业和文旅融合路径

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
